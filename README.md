# Last Text at One Percent

The funniest final text a dying phone sends at one percent battery,
under 200 characters, in the voice of the dying phone itself. The phone
knows everything — the passcode, the 3am searches, the text never sent
to the ex — and it is taking it all to the grave. Which is right now.
